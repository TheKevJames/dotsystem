description: Build a plan for solving an issue
---

Determine a plan for solving the following issue. Iterate on the plan by asking
me questions until you have a full understanding of the problem statement and
my prefered approaches to solving it. Do not make code changes, but you are
allowed to write throw-away code to test the viability of any options which are
in question when we're in doubt.

Keep the overall plan high-level until I approve it, then draft a detailed,
step-by-step blueprint for implementing our plan. Break it into small,
iterative chunks that build upon each other. Looks at these chunks and break
them into self-contained steps. Review the results and make sure the steps are
small enough to be implemented safely with strong testing, but big enough to
move the project forward. Iterate until the steps are right-sized for this
project.
